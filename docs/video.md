# 视频渲染规范

把策略跑出来的轨迹变成能对外展示的素材。原则：**好看，但不撒谎**。

## 1. 三种素材，别混着说

| 类型 | 动作来源 | 允许的标注 | 用途 |
| --- | --- | --- | --- |
| 模型闭环 | 策略网络输出 | `actions from the model` | 汇报主素材 |
| 专家示教 | 脚本 IK/专家策略 | `scripted expert` | 证明环境与链路可用 |
| 混合 | 模型 + 脚本修补 | 必须逐段说明 | 尽量别用 |

## 2. 录一条模型视频

```bash
python scripts/render_demo.py \
  --model <X-VLA-WidowX 权重> \
  --head out/head_v7.pt \
  --episodes 1 --chunks 11 \
  --out out/model_pick.mp4
```

脚本做的事：渲染 224×224 观测 → 策略出 30 步动作 → 示教流形最近邻转关节 → 物理步进 → 每 N 步抓一帧双视角 → 叠加字幕 → 写 MP4。

## 3. 画面规范

- **双视角**：左 = 策略实际看到的视角（数据机位），右 = 近景；观众能对上"它看到什么"和"它做了什么"
- **字幕三条**：环境（MuJoCo/Unity）、机器人型号、动作来源
- **成功率**：写清样本数（`8/8`、`20 条目标`），不要只写百分比
- **禁止**：把脚本专家剪成模型输入输出、加速播放掩盖抖动、裁掉失败片段还声称连续成功

## 4. 交付前自查

- [ ] 字幕写明"仿真"
- [ ] 字幕写明动作来源
- [ ] 成功率有分子分母
- [ ] 视频时长 10–20 秒（超过 30 秒没人看完）
- [ ] 文件 < 10 MB，H.264，1920×1080 以内

## 5. 已知限制（别被追问时答不上来）

- MuJoCo 与 Unity 是两个渲染器，**同一权重不能直接跨过去用**（外观即分布外）
- 当前最好的成绩是单物体抓取 8/8；多物体分拣、工业外观仍在攻关
- 所有结果都在仿真里，真机与 M50 板端未验证
